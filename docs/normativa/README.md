# Normativa

Cada regla que use el motor tiene una ficha en esta carpeta. Sin ficha, no se implementa.

## Plantilla de ficha

Copiar en un archivo nuevo, por ejemplo `R001-edad-jubilatoria-regimen-general.md`.

```markdown
# R000 — Nombre de la regla

- **Estado:** Borrador | En revisión | Validada
- **Validada por:** (previsionalista, fecha)

## Norma y fuente
- Norma: (ley, decreto, resolución y artículo)
- Fuente verificable: (link a InfoLEG / Boletín Oficial)

## Vigencia
- Desde / hasta

## Modificaciones
- (normas que la modificaron, con fecha)

## Excepciones
- (casos donde no aplica o aplica distinto)

## Enunciado
Qué dice la regla, en lenguaje claro.

## Criterios de aceptación
- Dado ..., cuando ..., entonces ...

## Casos de prueba
| Entrada | Resultado esperado | Fuente del caso |
|---------|--------------------|-----------------|
```
