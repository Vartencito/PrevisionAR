# Prueba de la v0.1 con abogados (issue #22)

Guía para el responsable. Una sesión de unos 45 minutos con cada abogado, idealmente mirando cómo usa el programa sin ayudarlo.

## Antes

- Tener la versión descargable publicada (issue #19, después de decidir la licencia en #20) o llevar una PC con el programa abierto.
- Imprimir esta hoja.
- Pedirle que traiga **un caso propio ya resuelto por ANSES** (resolución o cómputo), con los datos personales tapados. Es la mejor prueba y además puede ser un caso dorado.

## Durante

1. **Primer contacto (5 min):** que lo abra solo siguiendo la [guía de uso](../guia-de-uso.md). Anotar dónde se traba.
2. **Un ejemplo (5 min):** que cargue un ejemplo de la lista y calcule. ¿Entiende el resultado sin explicación?
3. **Su caso (20 min):** que cargue su caso real (en su PC; los datos no salen de ahí) y compare con lo que dijo ANSES.
4. **Informe (5 min):** que lo imprima o lo guarde como PDF. ¿Lo usaría?
5. **Guardar (5 min):** que guarde el caso, cierre el programa y lo vuelva a abrir.
6. **Preguntas finales (5 min):** las de abajo.

## Qué anotar

| Tema | Pregunta | Respuesta |
|------|----------|-----------|
| Resultado | ¿Coincidió con ANSES? Si no, ¿en cuánto y en qué tramo? | |
| Confianza | Del 1 al 5, ¿cuánto confiaría en el resultado para su trabajo? ¿Qué lo haría subir? | |
| Velocidad | ¿Cuánto tardó en cargar su caso? ¿Cuánto tarda hoy con su método? | |
| Lo que más le sirvió | | |
| Lo que le faltó | ¿Qué es lo primero que tendría que hacer el programa para que lo use todos los días? (moratorias, cómputo por hijos, haber, leer la historia de ANSES…) | |
| Lo que confunde | Palabras, pantallas o pasos que no entendió | |
| Comparación | ¿En qué es mejor o peor que lo que usa hoy (BlueCorp, Jáuregui, planilla)? | |
| Validación | ¿Aceptaría revisar los criterios marcados "a validar" del informe? ¿Tiene más casos de ANSES para pasarnos? | |

## Después

- Pasarle a la IA las respuestas tal cual. Si se compararon casos reales, **tapar los datos personales** antes.
- La IA arma la nota en `reuniones/AAAA-MM-DD.md`, convierte los pedidos en issues y propone el orden de la v0.2 según lo que pidieron.
