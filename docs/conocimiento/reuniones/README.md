# Notas de reuniones con abogados

Una nota por reunión: `AAAA-MM-DD.md`. La escribe la IA a partir de lo que trae el responsable (respuestas tal cual, transcripción o resumen).

Cada nota tiene:

- **Fecha, quién participó** (rol, por ejemplo "abogado previsionalista 1"; el nombre solo si el abogado está de acuerdo) y **qué hoja se usó**.
- **Respuestas**, con el código de cada pregunta (`P-14`, `R006-3`, `A2-bis`). Las respuestas también se copian a `../preguntas-previsionalista.md`.
- **Pedidos y opiniones** sobre el programa, que se convierten en issues.
- **Pendientes:** qué quedó para la próxima.

Reglas: sin datos de clientes y sin copiar material de terceros (cursos, apuntes). Si el abogado mostró un documento, se resume con palabras propias y se cita de dónde salió.
